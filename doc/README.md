# A股 · 四线资金博弈分时图

> 浏览器里查看中国 A 股个股 / 指数的「机构 / 主力 / 中户 / 散户」四类资金流向数据。
> 最新交易日按分时（240 分钟）展示，历史日期按日级汇总。

## 项目概览

| 项 | 说明 |
|---|---|
| 目录 | `C:\Users\PC\Documents\stockstock analysis\` |
| 访问地址 | http://127.0.0.1:8765/ |
| 技术栈 | 原生 HTML/JS/CSS + ECharts + Python 本地代理 |
| 启动方式 | `start.bat` 或 `start.ps1` |
| 停止方式 | `stop.bat` 或 `stop.ps1` |
| 默认标的 | 上证指数 `000001` |

把东方财富的两个公开接口包成一个极简交易终端 UI 的单页应用，跑在本地 8765 端口。

## 核心功能

- **代码输入 + 自动识别市场**
  - `6/9/5` 开头 → 沪市 (market=1)
  - `0/3` 开头 → 深市 (market=0)
  - 数字开头 → 自动挨个市场试
- **指数代码库自动消解**
  - 内置 16 个常用 A 股大盘指数白名单，避免 `000001` 既是上证指数又是平安银行、`399006` 是创业板指等代码冲突
  - 不知归属时优先尝试沪市
- **双图表模式**
  - **最新交易日** → 四线分时折线图（240 个分钟点累计净流入）
  - **历史某日** → 四线横向柱状图（机构 / 主力 / 中户 / 散户各一条带数值标签）
- **指数 vs 个股智能切换**
  - 指数：上证指数 / 深证成指 / 创业板指 / 沪深 300 / 上证 50 / 科创 50 / 中证 500
  - 个股：贵州茅台 / 平安银行 / 宁德时代 / 招商银行 / 中国平安 / 中芯国际
  - 指数与个股的默认市场差异已在 `INDEX_MARKET` 集中处理
- **日期快捷选择**
  - 自动列出最近 10 个有数据的交易日
  - 默认选中最新交易日
- **数据来源**
  - 主源：本地代理 `/api/minute` 与 `/api/daily`
  - 备源：东方财富官方公开接口（直连）
  - 全部失败时降级到本地模拟数据，UI 会标注「行情源不可达」

## 启动方式

### 快速启动

双击 `start.bat`（或右键 `start.ps1` → 使用 PowerShell 运行）。
脚本会自动：
1. 检查 8765 端口是否被占用，被占用则终止旧进程
2. 用 Python 启动 `server.py`
3. 打开浏览器到 http://127.0.0.1:8765/

### 手动启动

```powershell
cd "C:\Users\PC\Documents\stockstock analysis"
python server.py
```
然后浏览器访问 http://127.0.0.1:8765/

### 停止服务

双击 `stop.bat`（或右键 `stop.ps1` → 使用 PowerShell 运行）。
它会找出占用 8765 端口的进程并结束它，再清理本目录下残留的 `server.py`，最后回报端口是否已释放。
服务本身未运行时也可安全执行，会直接提示无需停止。

## 使用说明

1. 在搜索框输入 6 位股票代码，例如 `000001` / `600519` / `300750`
2. 点击「加载」按钮或按回车
3. 顶部日期条点击不同日期切换分时 / 日级
4. 信息条显示代码 / 名称 / 日期 / 四类资金流向数值
5. 鼠标悬停图表查看分钟级详情

## 数据格式

每条 kline（分时点）包含 6 个字段：

```
时间, 主力净流入, 中户净流入, 散户净流入, 主力净额, 中户净额
2025-09-26 09:31, -724832240, 565942272, 158291200, -465309440, -259522800
```

四线定义：
- **机构（JG）** — 超大单
- **主力（ZL）** — 大单
- **中户（ZH）** — 中单
- **散户（SH）** — 小单

## 已知限制

- 仅供学习研究使用，不构成投资建议
- 东方财富接口偶发限流，代理已内置 4 次重试
- 分时仅展示最近 1 个交易日，日级展示最近 10 个交易日
- 数据有 15 分钟延迟（东方财富公开接口特性）
