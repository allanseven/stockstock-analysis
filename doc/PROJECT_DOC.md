## 核心功能

### 1. 智能代码识别
- **自动市场识别**：输入 6 位代码后自动识别沪市/深市
  - `6/9/5` 开头 → 沪市（market=1）
  - `0/3` 开头 → 深市（market=0）
  - 数字开头 → 自动尝试多个市场
- **指数代码白名单**：内置 16 个常用 A 股大盘指数，避免代码冲突（如 000001 既是上证指数又是平安银行）

### 2. 双图表模式
- **最新交易日**：四线分时折线图（240 个分钟点累计净流入）
- **历史日期**：四线横向柱状图（机构/主力/中户/散户各一条带数值标签）

### 3. 四线资金流向
- **机构（JG）**：超大单资金流向
- **主力（ZL）**：大单资金流向
- **中户（ZH）**：中单资金流向
- **散户（SH）**：小单资金流向

### 4. 快捷操作
- **指数快捷**：上证指数、深证成指、创业板指、沪深 300、上证 50、科创 50、中证 500、中证 1000
- **个股快捷**：贵州茅台、平安银行、宁德时代、招商银行、中国平安、中芯国际
- **板块/ETF**：银行板块、证券板块、CPO 概念、科创半导体 ETF
- **日期选择**：自动列出最近 10 个有数据的交易日

### 5. 详细信息弹窗
- 点击股票名称可查看详细信息
- 支持分时、日 K、周 K、月 K 多种视图
- 展示行情数据、估值与标的信息
- 集成 MACD 技术指标

## 技术架构

### 前端架构
```
index.html    → 页面骨架（头部/搜索/日期条/信息条/图表/详情弹窗）
style.css     → 视觉样式（暗色主题，响应式布局）
app.js        → 数据获取、解析、UI 渲染（ECharts 图表）
```

### 后端架构
```
server.py     → Python 本地反向代理服务器
              - 静态文件托管
              - API 反向代理（东方财富接口）
              - CORS 跨域支持
              - 4 次重试机制
```

### API 端点
| 端点 | 功能 | 数据源 |
|------|------|--------|
| `/api/minute` | 分时资金流向 | 东方财富 push2 API |
| `/api/daily` | 日级资金流向 | 东方财富 push2his API |
| `/api/quote` | 行情快照 | 东方财富 push2 API |
| `/api/kline` | K 线数据 | 东方财富 push2his API |
| `/api/detail` | 详细信息 | 东方财富 push2 API |
| `/api/trends` | 分时走势 | 东方财富 push2 API |

### 数据容错机制
1. **主源**：本地代理 `/api/*`
2. **备源**：东方财富官方接口（直连）
3. **降级**：全部失败时使用本地模拟数据，UI 标注「行情源不可达」

## 启动方式

### 方式一：一键启动（推荐）
双击运行 `start.bat` 或 `start.ps1`，脚本会：
1. 检查 8765 端口是否被占用，被占用则终止旧进程
2. 用 Python 启动 `server.py`
3. 自动打开浏览器到 http://127.0.0.1:8765/

### 方式二：手动启动
```powershell
cd "C:\Users\PC\Documents\stockstock analysis"
python server.py
```
然后浏览器访问 http://127.0.0.1:8765/

---

### 方式三：停止服务

双击运行 `stop.bat` 或 `stop.ps1`，脚本会：

1. 查出占用 8765 端口的进程并强制结束它
2. 清理本目录下残留的 `server.py` 进程
3. 回报端口是否已释放（未运行时会直接提示无需停止）

## 使用说明

### 基本操作
1. **输入代码**：在搜索框输入 6 位股票代码（如 `000001`、`600519`、`300750`）
2. **加载数据**：点击「加载」按钮或按回车键
3. **切换日期**：顶部日期条点击不同日期查看分时/日级数据
4. **查看详情**：点击股票名称打开详细信息弹窗
5. **快捷操作**：点击快捷栏按钮快速加载常用标的

### 界面说明
- **顶部导航栏**：品牌标识 + 搜索框 + 状态指示
- **快捷栏**：指数/个股/板块 ETF 快捷按钮
- **日期条**：最近 10 个交易日选择器
- **信息条**：代码/名称/日期/涨跌幅/四线资金流向数值
- **图表区**：ECharts 渲染的资金流向分时图/柱状图
- **详情弹窗**：股票详细信息（分时/K 线/行情/估值）

## 数据格式

### 分时数据（kline）
每条包含 6 个字段：
```
时间, 主力净流入, 中户净流入, 散户净流入, 主力净额, 中户净额
示例: 2025-09-26 09:31, -724832240, 565942272, 158291200, -465309440, -259522800
```

### 四线定义
| 线条 | 颜色 | 含义 | 订单类型 |
|------|------|------|----------|
| 机构（JG） | #ff5b5b 红色 | 超大单资金流向 | 机构交易 |
| 主力（ZL） | #ffb020 橙色 | 大单资金流向 | 主力交易 |
| 中户（ZH） | #4fa8ff 蓝色 | 中单资金流向 | 中户交易 |
| 散户（SH） | #5fd49a 绿色 | 小单资金流向 | 散户交易 |

## 技术特性

### 前端特性
- **SVG 渲染**：ECharts 使用 SVG 渲染器，避免 GPU 合成撕裂
- **响应式布局**：适配桌面和移动端
- **暗色主题**：专业的金融终端视觉风格
- **动画效果**：状态指示、通知提示、输入校验
- **本地存储**：无状态设计，每次重新加载数据

### 后端特性
- **轻量级**：纯 Python 标准库实现，无需额外依赖
- **反向代理**：封装东方财富公开接口
- **重试机制**：4 次自动重试，应对网络波动
- **CORS 支持**：允许跨域请求
- **TLS 处理**：禁用 SSL 验证（本地代理专用）

---

## 已知限制

1. **使用限制**：仅供学习研究使用，不构成投资建议
2. **接口限制**：东方财富接口偶发限流，代理已内置重试
3. **数据范围**：分时仅展示最近 1 个交易日，日级展示最近 10 个交易日
4. **数据延迟**：数据有 15 分钟延迟（东方财富公开接口特性）
5. **网络依赖**：需要访问东方财富 API，离线环境会使用模拟数据
